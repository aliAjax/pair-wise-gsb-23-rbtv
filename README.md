# hxwl-09 半导体洁净室巡检

洁净等级阈值、粒子计数与异常处理看板

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 功能

- **阈值版本化判定**：新建巡检按当班（当前生效）阈值版本判定，记录保存阈值快照；发布新阈值只影响之后的新记录，历史记录仍按原版本显示判定
- **判定规则**：达到/超过上限（含等于上限）或低于下限即判异常，录入时实时预判
- **复核锁定**：厂务工程师复核通过后记录锁定，任何人不能再修改
- **乐观并发控制**：记录带版本号，两个页面（标签页）同时编辑同一记录时，晚提交的人会看到版本冲突提示，草稿保留不丢失，也不会覆盖对方刚保存的结果；可选择放弃草稿或基于最新版本重新编辑
- **本地持久化**：未提交草稿、已提交记录、审计轨迹均存于 localStorage，页面中途关闭后自动恢复；多标签页通过 storage 事件实时同步
- **导出摘要**：CSV 导出，每行带记录版本与阈值版本
- **角色权限**：巡检员（录入/编辑）、厂务工程师（录入/复核/发布阈值）、班组长（只读+导出）
- **审计轨迹**：新建、更新、复核、发布阈值、版本冲突、导出等操作全部留痕
